# FG-TIDA WG0: Use Cases, Taxonomy and Terminology (UCT)

WG0 maintains the shared terminology and the shared use-case register that every other FG-TIDA Working Group relies on.

## Contributing
- **Submit a use case:** open a [new issue](https://github.com/fg-tida-wg0/use-cases/issues/new/choose) in [`use-cases`](https://github.com/fg-tida-wg0/use-cases) using the use-case template — no pull request needed.
- **Propose a charter or terminology change:** see `CONTRIBUTING.md` in the relevant repository — open an issue or a pull request; do not push directly to `main`.
