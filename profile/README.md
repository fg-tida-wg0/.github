# FG-TIDA WG0: Use Cases, Taxonomy and Terminology (UCT)

WG0 maintains the shared use-case register and shared vocabulary that every other FG-TIDA Working Group depends on. Any Working Group or anyone else can submit a use case into the register or draw out the ones tagged to it; any Working Group can reuse WG0's terminology instead of defining its own.

WG0 produces four things, in this order: a use-case register (real scenarios, drawn from submissions), terminology (one agreed meaning per term, or both meanings clearly labeled where two are genuinely needed), a taxonomy (a fixed set of labels for sorting use cases so two different ones can be compared on the same terms), and an ontology (a small, formal statement of how taxonomy concepts relate to each other, built only as far as a specification or tool will actually use it). Each depends on the one before it: taxonomy work does not start until the register holds enough use cases to sort meaningfully.

> **Status:** Charter v0.10, draft, presented for approval at the FG-TIDA Paris meeting, 30 November 2026.

## Contributing
- **Submit a use case:** open a [new issue](https://github.com/fg-tida-wg0/use-cases/issues/new/choose) in [`use-cases`](https://github.com/fg-tida-wg0/use-cases) using the use-case template, no pull request needed.
- **Propose a charter or terminology change:** see `CONTRIBUTING.md` in the relevant repository, open an issue or a pull request; do not push directly to `main`.
